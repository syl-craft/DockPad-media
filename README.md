# DockPad — media

Demo clips for [DockPad](https://github.com/syl-craft/DockPad), kept out of the main repository so
cloning it stays light. The [DockPad README](https://github.com/syl-craft/DockPad#readme) embeds
them from here.

| Clip | Shows |
|---|---|
| `01-launcher` | Global hotkey, launching a tile, pages, search |
| `02-browser-picker` | Picking a browser per link, per-domain rules, favourites |
| `03-usage` | AI usage quotas, Claude and Codex tabs, alert threshold |
| `04-secrets` | Right-click → Inject secrets, rendered straight to the clipboard |
| `05-keyboard` | Keyboard overlay and page switching |
| `06-composite` | 2 × 2 and 2 + 4 composite tiles |

Each clip exists in `light` and `dark`, as an MP4 (1920 × 1080, 60 fps, 10 s) and a GIF
(960 × 540, 20 fps) for the README. Demo data only.

These files are **generated** — do not edit them by hand. They are rendered by
[`tools/MotionDemo`](https://github.com/syl-craft/DockPad/tree/master/tools/MotionDemo) in the
DockPad repository, which writes straight into `videos/` here when this repository sits next to it.
